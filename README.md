# 공문정리함제출

**에듀파인에서 내려받은 공문 파일을 읽어, "무엇을 언제까지 해야 하는지"를
화면 구석의 작은 창에 정리해 주는 프로그램입니다.**

공문을 읽고, 기한을 찾고, 업무 종류를 가르고, 끝난 일을 월별 폴더로
옮기는 일을 대신합니다. 모든 처리는 이 컴퓨터 안에서만 이루어집니다.

---

## 1. 바로 실행해 보기

파이썬이나 다른 프로그램을 따로 설치할 필요가 없습니다. 관리자 권한도
필요 없습니다.

1. **`gongmun-submisson-setup.exe`** 를 두 번 누르고 "다음" 을 눌러 설치합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
     코드 서명 인증서가 없는 프로그램에 윈도우가 띄우는 창입니다.
   - 설치하지 않고 **`gongmun-submisson.exe`** 를 바로 실행해도 똑같이 동작합니다.
2. 처음 켜면 공문을 모아 둘 폴더를 묻습니다. **확인** 을 누르면
   `문서\공문` 폴더가 만들어집니다.

화면 오른쪽 위에 기한이 가까운 공문부터 정리된 작은 창이 뜹니다.
작은 창에서 공문을 누르면 브라우저에 전체 화면이 열립니다.

> 확인한 실행 환경: Windows 11 64bit. 한글이나 MS Office 가 설치되어 있지
> 않아도 파일을 읽습니다. 인터넷이 끊겨 있어도 모든 기능이 동작합니다.

---

## 2. 어떤 문제를 푸는가

학교 업무 담당자는 매일 여러 건의 공문을 받습니다. 공문 한 건을 처리하려면
늘 같은 손일을 반복해야 합니다.

| 지금까지의 손일 | 이 프로그램이 하는 일 |
|---|---|
| 본문과 첨부가 따로 내려받아져 폴더에 흩어진다 | 파일 이름의 **접수번호**로 본문과 첨부를 한 건으로 묶고, 공문마다 제목 폴더를 만들어 넣는다 |
| 제출 기한이 본문이 아니라 **첨부 서식에만** 적혀 있어 놓친다 | 본문과 첨부를 모두 읽어 **가장 이른 기한**을 찾는다 |
| "신청 기한"과 "행사 날짜"가 한 문서에 섞여 헷갈린다 | 문장을 보고 **기한**과 **행사일**을 구분한다 |
| 내가 해야 할 일인지, 읽고 넘길 안내인지 일일이 연다 | 본문을 보고 **제출·보고 / 일정·행사 / 신청·공모 / 배포·전달 / 안내·참고** 로 나눈다 |
| 끝난 공문을 월별 폴더로 옮기는 정리를 미룬다 | 처리한 공문을 **마감 월 폴더**로 한 번에 옮긴다 |
| 결재자가 말없이 고친 글자를 눈으로 찾기 어렵다 | 결재 전후 문서를 화면에서 견주어 **달라진 자리를 빨간 상자로** 보여 준다 |

## 3. 주요 기능

**바탕화면 작은 창**
- 기한이 가까운 순서로 공문이 늘어서고, 남은 날(D-4)과 업무 종류 색이 함께 보입니다.
- 10분마다 폴더를 다시 훑어, 새로 받은 공문이 저절로 올라옵니다.
- 원하는 자리에 끌어다 두면 그 자리를 기억합니다. 화면 가장자리에 가까이 놓으면 가장자리에 딱 붙습니다.

**전체 화면**
- 본문과 첨부 문서를 **문서 모양 그대로** 미리 봅니다. 표도 문서에 보이던 그대로 나옵니다.
- 기한이나 업무 종류가 틀렸으면 바로 고칠 수 있고, 고친 값이 항상 우선합니다.
  본문에서 찾은 날짜를 한 번 누르면 그 날짜가 기한이 됩니다.
- 기한 지난 공문을 한꺼번에 골라 처리 완료로 넘길 수 있고, 잘못 눌렀으면
  **Ctrl+Z** 로 되돌립니다.
- **일정 내보내기** 를 누르면 달력 파일(.ics)을 만듭니다. 구글 캘린더 등에서 불러옵니다.

**폴더 정리**
- **폴더 정리**: 공문마다 제목을 딴 폴더를 만들어 본문과 첨부를 넣습니다.
- **완료된 업무 정리**: 처리를 마친 공문을 `8월\`, `9월\` 같은 마감 월 폴더로 옮깁니다.
- 두 기능 모두 어떤 파일이 어디로 옮겨질지 **먼저 보여 주고 물어본 뒤** 옮깁니다.

**업무 도우미 (작은 창의 서랍)**
- **결재 전후 비교**: 원본과 수정본이 보이는 화면 영역을 차례로 끌어 고르면,
  달라진 곳을 빨간 상자로 표시합니다. 글자가 아니라 화면에 보이는 모양을
  견주므로 한글이든 PDF든 상관없습니다.
- **커스텀 클립보드**: 자주 쓰는 문구와 특수문자(○ ※ ℃ 등)를 모아 두고, 누르면 바로 복사됩니다.
- **도구 서랍**: 에듀파인, 자주 여는 업무 폴더, 서식 파일을 등록해 두고 한 번에 엽니다.

**읽을 수 있는 파일**: hwpx, hwp, pdf, xlsx, xls, docx, txt

## 4. 안전과 개인정보

- **공문 내용은 밖으로 나가지 않습니다.** 읽은 내용은 이 컴퓨터의
  `C:\Users\(사용자)\.gongmun-submisson` 폴더에만 저장됩니다.
- 화면은 이 컴퓨터 안에서만 열립니다(127.0.0.1). 같은 망의 다른 컴퓨터에서는
  접속할 수 없고, 윈도우 방화벽 허용 창도 뜨지 않습니다.
- 인터넷을 쓰는 것은 **새 버전이 있는지 확인하는 일 하나뿐**이며, GitHub 에만
  접속하고 버전 번호 외에는 아무것도 보내지 않습니다.
- **원본 파일은 지우지 않습니다.** 폴더 정리 중 똑같은 파일을 또 받은 경우에만
  그 중복 파일을 휴지통으로 보내며, 휴지통에서 되살릴 수 있습니다.
- 내용을 읽는 곳은 `공문` 폴더 한 곳뿐입니다. 월별 폴더에 섞여 있을 수 있는
  다른 업무 파일(개인정보가 든 파일 등)은 옮기기만 하고 열어 보지 않습니다.
- 결재 전후 비교에서 찍은 화면은 저장하지 않으며, 창을 닫으면 사라집니다.

---

## 5. 알려진 한계

- 스캔한 PDF(글자가 아닌 그림)와 암호가 걸린 파일은 읽지 못합니다. 이런 공문도
  목록에는 올라오지만 "미분류" 로 들어갑니다.
- hwp 파일은 표 안의 글자가 빠질 수 있습니다. 한글에서 hwpx 로 저장하면 가장 정확합니다.
- 업무 종류와 기한은 문장 규칙으로 판단하므로 틀릴 수 있습니다. 판단 근거가 약한
  공문에는 **확인 필요** 표시가 붙고, 화면에서 고친 값이 항상 우선합니다.

## 6. 함께 제출한 자료

| 파일 | 내용 |
|---|---|
| `gongmun-submisson-setup.exe` | 설치 파일 |
| `gongmun-submisson.exe` | 설치 없이 바로 실행하는 파일 |
| `사용설명서.txt` | 사용자(교사)용 자세한 사용 방법 |
| `예시공문` 폴더 | 가상 기관·인물(OO교육청, OO중학교, 김OO 등)로 만든 공문 8건(기한 9월·10월·11월·없음)과 결재 전후 비교용 기안문 2건 |
| 소스 폴더 | 프로그램 전체 소스와 자동 테스트 |
| `개발자안내.md` | 소스로 실행·빌드하는 방법, 분류 규칙 손보는 법 |
| `LICENSE`, `THIRD-PARTY-NOTICES.txt`, `licenses` 폴더 | MIT 라이선스, 함께 쓰인 라이브러리·글꼴·파이썬 구성 요소의 저작권 표시와 라이선스 전문 |

**만든 방법**: Python 으로 만들었습니다. 파일을 읽어 분류하는 엔진, 브라우저로 여는
전체 화면, 바탕화면 작은 창이 함께 들어 있으며, 하나의 exe 로 묶어 배포합니다.
자동 테스트 338개로 분류·기한 판단, 파일 정리, 인터넷이 없는 환경,
외부 접속 차단 등을 점검합니다.
