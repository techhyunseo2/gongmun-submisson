# 공문정리함제출

폴더에 모아 둔 공문 파일을 훑어서 **내가 무엇을 해야 하는지** 기준으로 분류하고,
기한이 가까운 순서로 한 화면에 보여 줍니다. 전부 내 컴퓨터 안에서만 돌아갑니다.

> 이 문서는 소스를 손보는 사람을 위한 것입니다.
> 파이썬이 없는 컴퓨터에서는 소스 대신 함께 드린 `gongmun-submisson-setup.exe`(설치) 또는 `gongmun-submisson.exe`(설치 없이 실행)를 쓰시면 됩니다.
> 프로그램을 받아 쓰는 분께는 **사용설명서.txt** 를 함께 주시면 됩니다.

## 무엇을 해 주나

- 폴더 안의 `.hwpx` `.hwp` `.pdf` `.xlsx` `.xls` `.docx` `.txt`를 읽어 본문을 뽑습니다.
- **공문 하나를 묶음으로 다룹니다.** 에듀파인 파일 이름 앞머리의 접수번호
  (`[예시중학교-4971]`)로 본문과 첨부를 잇습니다. `폴더 정리`를 누르면
  묶음마다 폴더를 만들어 파일을 넣어 줍니다. 목록에는 한 줄로 뜨고, 열면
  딸린 문서를 눌러 가며 미리볼 수 있습니다.
- 기한은 본문뿐 아니라 첨부까지 살펴 가장 이른 것을 씁니다. 제출 서식에만
  기한이 적혀 있는 경우가 흔하기 때문입니다. 다만 화면에서 손으로 정한
  기한이 있으면 그것이 항상 우선하고, 다시 분석해도 지워지지 않습니다.
- 규정이나 지침의 부칙에 적힌 옛날 시행일은 기한으로 보지 않습니다.
  오늘로부터 400일보다 더 지난 날짜는 걸러 냅니다.
- 엑셀 첨부는 시트마다 나눠서 보여 줍니다.
- 끝난 일은 `완료된 업무 정리`로 마감 월 폴더에 넣습니다. 아래 구조를 씁니다.
- 본문을 보고 여섯 가지 업무 유형으로 나눕니다.
  - **제출·보고** — 기한 안에 자료를 만들어 보내야 하는 것
  - **일정·행사** — 참석하거나 학교에서 실시해야 하는 날짜가 있는 것
  - **신청·공모** — 신청할지 말지 내가 고르는 것
  - **배포·전달** — 학생이나 학부모에게 전달해야 하는 것
  - **안내·참고** — 읽고 알아두면 끝나는 것
  - **미분류** — 판단이 서지 않은 것
- 본문에서 날짜를 찾아 **기한**과 **행사일**을 구분합니다.
  `접수 기간: 9. 1. ~ 9. 5.`처럼 기간이 적혀 있으면 끝 날짜를 기한으로 봅니다.
  `참가 신청은 9. 18.까지`와 `일시: 9. 24.`가 같이 있으면 앞은 기한, 뒤는 행사일이 됩니다.
- 기한 지남 / 오늘·내일 / 이번 주 / 한 달 안 순서로 줄을 세웁니다.
- 유형이나 기한이 틀렸으면 화면에서 바로 고칠 수 있고, 고친 값이 우선합니다.
- 기한을 못 잡았을 때는 `본문에 나온 날짜`의 날짜를 누르면 바로 기한이 됩니다.
  같은 날짜를 다시 누르면 해제됩니다.
- 목록에서 여러 건을 골라 한꺼번에 처리 완료로 옮길 수 있습니다. 머리말의
  `기한 지난 N건 모두 고르기`로 한 번에 찍은 뒤, 아직 참고해야 하는 것만
  체크를 풀면 됩니다. 구간 이름 옆 `이 구간 모두`로 구간 단위로도 고를 수 있고,
  머리말 오른쪽 `모두 고르기`는 지금 화면에 보이는 것만 고릅니다. 유형을 걸러 둔
  상태면 그 유형만 골라집니다. 다 골라져 있으면 같은 자리가 `모두 해제`가 됩니다.
- `일정 내보내기`를 누르면 `.ics` 파일이 만들어집니다. 구글 캘린더나 학사일정 앱에서 가져오면 됩니다.

## 바탕화면 위젯

`위젯.bat`을 더블클릭하면 검은 콘솔 창 없이 작은 패널만 뜹니다. 명령으로 실행하려면

```
pythonw widget.py
```

테두리 없는 창이 화면 오른쪽 위에 뜨고, 기한이 가까운 공문 일곱 건을 보여 줍니다.

- **머리말을 끌면** 창이 움직이고, 놓은 자리를 기억해 다음에도 같은 곳에 뜹니다.
- **아무 줄이나 누르면** 브라우저에 전체 화면이 열립니다. 위젯과 전체 화면은 같은 프로그램이라
  한쪽에서 처리 완료로 옮기면 다른 쪽에도 반영됩니다.
- **제목 아래 폴더 줄**을 누르면 공문 폴더와 업무 루트의 전체 경로가 뜨고,
  거기서 폴더를 열거나 바꿀 수 있습니다.
- **오른쪽 버튼**을 누르면 항상 위에 두기, 투명도, 폴더 열기를 고를 수 있습니다.
- **—** 를 누르면 머리말만 남기고 접힙니다.
- 10분마다 폴더를 자동으로 다시 훑습니다. 새 공문을 받아 폴더에 넣으면 곧 목록에 올라옵니다.

### 컴퓨터를 켤 때 자동으로 띄우기

`윈도우 키 + R` → `shell:startup` → 열린 폴더에 `위젯.bat` 바로가기를 넣어 두면 됩니다.

### 위젯만 exe로 만들기

```
pyinstaller --onefile --noconsole --add-data "ui.html;." --name 공문위젯 widget.py
```

`--noconsole`을 빼면 뒤에 검은 창이 같이 뜹니다.

## 업무 폴더 구조

선생님들이 흔히 쓰는 방식을 그대로 따릅니다.

```
1. 교무기획/                 ← 업무 루트
   공문/                     ← 받은 공문이 쌓이는 곳
      파견교사 선발 계획 알림/    ← 폴더 정리로 만들어짐
         (본문).pdf
         (첨부).hwp
   8월/                      ← 완료된 업무 정리로 옮겨짐
      파견교사 선발 계획 알림/
   9월/
```

프로그램은 고른 폴더를 보고 구조를 알아냅니다. `공문` 폴더를 고르면 그 위를
업무 루트로 보고, 업무 루트를 고르면 그 안의 `공문` 폴더를 찾습니다.
월별 폴더는 `2월` 이든 `02월` 이든 같은 것으로 봅니다. 없으면 만듭니다.

**읽는 곳은 `공문` 폴더 한 곳뿐입니다.** 월별 폴더에는 공문 말고도 제출 자료나
개인정보가 든 파일이 섞여 있기 마련이라, 그쪽은 파일을 옮겨 넣기만 하고
내용을 들여다보지 않습니다. 업무 루트를 고르셔도 마찬가지입니다.

예전 버전이 월별 폴더까지 읽어 목록에 넣어 두었다면, 새 버전으로 한 번
훑는 순간 그 기록들이 지워집니다. 우리가 옮긴 공문(`8월 보관` 표시가 붙은 것)은
그대로 남습니다. 파일 자체는 어느 쪽도 건드리지 않습니다.

일이 도는 순서는 이렇습니다.

1. 에듀파인에서 받은 파일을 `공문` 폴더에 넣는다
2. `폴더 정리` — 접수번호로 본문과 첨부를 묶어 제목 폴더에 담는다
3. 처리한 것은 화면에서 `처리 완료` 를 누른다
4. `완료된 업무 정리` — 마감 월 폴더로 옮긴다

옮긴 뒤에도 기록은 남습니다. 목록에 `8월 보관` 이라고 표시되고 원본 열기도
그대로 됩니다. 마감일이 없는 공문은 행사일, 그것도 없으면 파일 날짜를 봅니다.
셋 다 없으면 옮기지 않고 그대로 둡니다.

## HWPX 양식 리더

`.hwpx`는 문서 구조를 그대로 따라가며 읽습니다. `hwpx_view.py`가 그 일을 합니다.

XML에서 글자만 훑어 모으면 표 안의 값이 문단 사이에 섞여 `구분 과목 희망 인원 중학교
기술·가정 2명`처럼 늘어져 어느 값이 어느 칸인지 알 수 없게 됩니다. 리더는 문단과 표,
셀을 구분해 읽어서 다음을 살립니다.

- 표는 표 그대로. 병합된 칸(`colSpan`, `rowSpan`)도 반영합니다.
- 탭으로 맞춘 `가. 나. 다.` 들여쓰기와 문단 왼쪽 여백
- 가운데·오른쪽 정렬, 굵게, 밑줄
- 줄바꿈과 빈 문단
- 그림이나 도형은 `[그림]`처럼 자리만 표시합니다

미리보기 오른쪽 위의 `글자만 보기`를 누르면 서식 없이 볼 수 있습니다.
분류와 날짜 추출에 쓰는 평문도 이 리더가 만들기 때문에, 표에서 뽑은 값은
`구분 | 과목 | 희망 인원`처럼 행 단위로 들어갑니다.

구조가 예상과 다른 파일을 만나면 예전 방식으로 물러나 글자만이라도 읽습니다.
`.hwp`는 표가 별도 레코드에 들어 있어서 아직 평문으로만 나옵니다. 표가 중요한 공문은
hwpx로 받아 두시는 게 낫습니다.

## 준비

파이썬 3.10 이상이 필요합니다. [python.org](https://www.python.org/downloads/)에서 설치할 때
**Add Python to PATH**를 꼭 체크하세요.

```
pip install -r requirements.txt
```

`olefile`은 구형 `.hwp`, `pypdf`는 `.pdf`를 읽는 데 씁니다.
설치하지 않아도 `.hwpx`와 `.docx`는 그대로 동작합니다.

## 실행

```
python app.py --folder "D:\공문"
```

폴더는 한 번만 지정하면 기억합니다. 다음부터는 `실행.bat`을 더블클릭하거나

```
python app.py
```

만 치면 됩니다. 브라우저가 열리면서 화면이 뜹니다.

| 명령 | 하는 일 |
|---|---|
| `python app.py` | 새로 들어온 파일만 분석하고 화면을 엽니다 |
| `python app.py --rescan` | 이미 읽은 파일까지 전부 다시 분석합니다 |
| `python app.py --folder "경로"` | 감시할 폴더를 바꿉니다 |
| `python app.py --no-browser` | 서버만 띄웁니다 |
| `pythonw widget.py` | 바탕화면 위젯을 띄웁니다 |

설정과 데이터베이스는 `사용자 폴더\.gongmun-submisson\`에 저장됩니다.

## 쓰는 법

공문을 다운받아 폴더에 넣고 화면에서 `다시 훑기`를 누르면 새 파일만 분석해 목록에 올라옵니다.
파일 내용으로 구분하기 때문에 이름을 바꾸거나 하위 폴더로 옮겨도 처리 상태는 그대로 따라옵니다.
폴더에서 파일을 지우면 목록에서도 사라집니다.

`확인 필요` 표시가 붙은 것은 판단 근거가 약했다는 뜻이니 한 번 열어 보세요.
행을 클릭하면 오른쪽에 본문 미리보기, 본문에서 찾은 날짜, 기한 근거 문장이 나옵니다.

## 분류 규칙 손보기

`classify.py`의 `_RULES`에 유형별 키워드와 가중치가 들어 있습니다. 제목에서 걸리면 가중치가
두 배로 반영됩니다. 학교에서 자주 오는 표현을 몇 개 더 넣으면 정확도가 눈에 띄게 올라갑니다.

```python
"submit": [
    ("제출", 5), ("회신", 5), ("수요조사", 5),
    ("기술가정", 4),          # 이런 식으로 추가
],
```

기한으로 볼 표현은 `_DEADLINE_CUES`, 다른 공문을 인용하는 줄을 걸러내는 규칙은
`_REFERENCE_LINE`에 있습니다.

## hwp 파일에 대해

- `.hwpx`는 표준 압축 XML이라 안정적으로 읽힙니다.
- `.hwp`는 한글 바이너리 형식을 직접 뜯어 읽습니다. 대부분 되지만 표 안에 든 글이나
  개체 안의 글은 빠질 수 있고, 암호가 걸린 파일은 읽지 못합니다.
- 잘 안 읽히면 한글에서 열어 **다른 이름으로 저장 → hwpx**로 바꿔 두는 게 가장 확실합니다.
  한글이 설치된 PC라면 폴더 전체를 hwpx로 일괄 변환해 두고 쓰는 방법도 있습니다.
- 스캔해서 만든 PDF는 글자가 없어서 읽지 못합니다. 목록에는 뜨지만 미분류로 들어갑니다.

## exe로 만들기

```
pip install -r requirements.txt pyinstaller
pyinstaller --clean --noconfirm build.spec
```

`dist\gongmun-submisson.exe`가 만들어집니다. (exe 이름은 영문이어야 합니다 —

## 개인정보

공문 본문은 전부 내 컴퓨터의 SQLite 파일에만 저장되고 **어디로도 보내지
않습니다.** 공문 내용이나 파일 이름이 바깥으로 나가는 일은 없습니다.

외부로 나가는 요청은 **새 버전이 있는지 확인하는 것 하나뿐**이며, 모두
GitHub 으로만 갑니다.

| 언제 | 어디로 | 무엇을 |
|---|---|---|
| 켤 때, 그 뒤 4시간마다 | `github.com/.../releases/latest` | 최신 버전 번호 확인 |
| 새 버전이 있을 때만 | `api.github.com` | 바뀐 점 설명글 |
| 갱신을 수락했을 때만 | `github.com/.../releases/download` | 새 실행 파일 |

이 요청들은 버전 번호 외에 아무것도 보내지 않습니다. 인터넷이 끊겨 있어도
프로그램은 그대로 동작하며, 갱신 확인만 조용히 건너뜁니다.

화면 글꼴(Pretendard)은 프로그램 안에 넣어 배포하므로 **글꼴 때문에 밖으로
나가는 요청은 없습니다.**
